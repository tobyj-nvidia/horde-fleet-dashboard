## Risk Assessment

### Critical Risk — Could Break Dashboard Silently

1. **`get_gpu_utilization` — division by zero risk**
   - Calculates `gpu_util_pct` = active GPU tasks / `gpu_capacity`
   - If `gpu_capacity = 0`, query will produce a divide-by-zero or NULL
   - The `gpu_panel.html` renders gauge bars based on this percentage
   - **Impact:** GPU panel crashes silently or shows NaN gauges

2. **`get_duration_percentiles` — NULL propagation**
   - Uses `PERCENT_RANK()` window function; returns `p50_sec`, `p95_sec`, etc.
   - If no completed tasks in window, all values may be NULL
   - `fragments.py` formats these values with Python string interpolation — None passed to template
   - **Impact:** Duration widget renders broken data or raises `TypeError`

3. **`retry_task` — mutation without test coverage**
   - Updates task status in the database (the only write query)
   - No test verifies the SQL correctness, row-not-found behavior, or idempotency
   - **Impact:** Retry button silently fails or corrupts task state

4. **`get_node_metrics_history` — downsampling edge case**
   - Uses `FLOOR(UNIX_TIMESTAMP(…) / (resolution_minutes * 60))` bucketing
   - No test for `resolution_minutes=1` vs `resolution_minutes=15` — different SQL paths
   - **Impact:** Node utilization charts render with wrong time buckets

### High Risk — Likely to Cause Incorrect Display

5. **`nodes.html` stale-node logic**
   - Template conditionally renders `stale` CSS class when `heartbeat_age_sec > 60`
   - No test verifies the boundary (exactly 60s, 59s, 61s)
   - **Impact:** Stale nodes not highlighted, or healthy nodes shown as stale

6. **`failures.html` — failure rate conditional styling**
   - Template highlights rows with `failure_pct > 10`
   - No test for the boundary condition
   - **Impact:** High-failure periods not visually flagged

7. **`get_tasks` — pagination with status filter**
   - The `status` filter passes a value from `VALID_STATUSES`; combined with `OFFSET`, could return wrong total
   - No test for offset-beyond-end or invalid status
   - **Impact:** Task list pager shows wrong total or empty data

### Medium Risk — Cosmetic / Non-Breaking

8. **`sparkline.py` — edge inputs**
   - `sparkline([])` and `sparkline([0, 0, 0])` behavior untested
   - **Impact:** Empty sparkline areas may render as blank or throw

9. **`charts.py` — SVG generation with empty data**
   - No test for `series=[]` or all-zero series
   - **Impact:** Empty node utilization chart may produce malformed SVG

10. **`_format_elapsed` — boundary formatting**
    - Converts seconds to "Xm Ys" string; no test for 0s, negative values, or very large values
    - **Impact:** Active tasks table shows wrong elapsed time formatting
